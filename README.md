# BiliGemi - BiliBili x Gemini B站視頻摘要

輕量化的 B 站影片字幕與觀眾評論 AI 摘要工具，支援 Chrome 內置 AI 與自訂 API 伺服器。

👉 **[BiliGemi 官方產品首頁](https://workingyuanyuan.github.io/BiliGemi-public/)**

---

## 🌟 核心特色
- **隱私安全**：無中轉伺服器，所有 API 密鑰儲存在本地，摘要過程直接與 AI 服務商通訊。
- **靈活配置**：支援多種主流 AI 模型，亦可使用免付費、免網路的 Chrome 內置 Gemini Nano。
- **快速摘要**：一鍵生成 Bilibili 影片字幕與觀眾評論的結構化大綱，省時高效。
