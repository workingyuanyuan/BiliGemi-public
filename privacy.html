BiliGemi 隱私權政策

生效日期 (Effective Date): July 12, 2026

1. 前言 / Introduction

歡迎使用 BiliGemi！我們非常重視您的個人隱私。本隱私權政策旨在說明本瀏覽器擴充功能（以下簡稱「本軟體」）如何處理、儲存及保護您的資料。

Welcome to BiliGemi! We value your privacy. This Privacy Policy details how this browser extension processes, stores, and protects your information.

2. 資料收集與使用 / Information Collection and Use

BiliGemi 是一款極致輕量化且注重隱私的輔助工具。我們採取以下原則處理您的資料：

  • 本機端運作 (Local Execution)： 所有的影片字幕與評論摘要邏輯皆在您的瀏覽器本機端執行。我們不會收集、記錄或上傳您的任何瀏覽紀錄、Bilibili 帳號資訊或個人識別資料。
  • AI API 通訊 (AI API Communication)： 當您使用摘要功能時，本軟體會將字幕或評論文字傳送給您所選擇的 AI 模型提供商（例如 Chrome 內建 AI 或是您自行配置的 OpenAI、DeepSeek、GLM、Moonshot、OpenRouter 等 API 伺服器）。此等通訊直接發生在您的瀏覽器與 API 提供商之間，不經過我們的任何中轉伺服器。
  • 本地儲存 (Local Storage)： 您的 API 金鑰（API Key）、自訂伺服器位址及個人設定僅儲存於您的瀏覽器本地儲存區 (chrome.storage) 中。

3. 第三方服務 / Third-Party Services

本軟體會與以下第三方服務進行直接通訊：

  • Bilibili API： 用於獲取您目前觀看影片的字幕與觀眾評論。
  • 您配置的 AI 服務商： 用於進行內容摘要與分析。請參閱您所選 AI 服務商（如 OpenAI、DeepSeek 等）的隱私權政策，以了解他們如何處理您的資料。

4. 政策變更 / Policy Changes

我們可能會不定期更新此隱私權政策。任何變更都會直接發布在此網頁上，並更新上方的生效日期。建議您定期檢視本頁面以獲取最新資訊。
